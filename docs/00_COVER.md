# How to use this guide

This document converts the research architecture into a controlled build sequence for a coding LLM. The accompanying implementation pack contains executable starter contracts: SQL schema, OpenAPI, event JSON Schema, environment blueprint, Docker Compose blueprint, traceability CSV, and per-phase prompts.

The guide intentionally corrects parts of the supplied UI mockups that would contradict the research. It does not claim that the proposed protocol is novel before the B3-versus-P1/P2 experiments are implemented and evaluated.
